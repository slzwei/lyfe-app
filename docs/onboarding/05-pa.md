# 5. PA Onboarding UAT

## Goal

Confirm a PA can be invited, assigned to a manager, and can work only with
candidate workflows for their assigned manager.

## Tester Setup

- Inviter account: Admin, Director, or Manager.
- Required existing account: active Manager the PA will support.
- New user account: PA.
- Technical verifier may be needed if PA-manager assignment is not available in UI.
- App needed: Lyfe mobile app.
- Do not use: ATS or MKTR.

## Preconditions

- Manager onboarding UAT has passed.
- At least one active manager exists.
- PA phone number can receive SMS OTP.
- PA phone number is not already used by another Lyfe user.
- The intended PA-manager assignment is known.

## Test Data

```text
Inviter role: Admin / Director / Manager
Assigned manager:
PA full name:
PA phone:
Environment:
App build:
Technical verifier, if used:
```

## Steps

| Step | Tester Action | Expected Result | Result |
|---|---|---|---|
| 1 | Log in as Admin, Director, or Manager. | Inviter lands on Home. |  |
| 2 | Go to Team. | Team screen opens. |  |
| 3 | Tap Invite Member. | Invite form opens. |  |
| 4 | Enter PA full name and 8-digit Singapore phone number. | Fields accept the data. |  |
| 5 | Select role `PA`. | PA is selected. |  |
| 6 | Tap Create Invitation. | Success message appears. |  |
| 7 | Check Team pending invitations. | PA invitation appears as pending. |  |
| 8 | Sign out of inviter, or switch to the PA device. | Login screen is ready for PA. |  |
| 9 | PA enters the same invited phone number. | OTP request is accepted. |  |
| 10 | PA enters SMS OTP. | Login succeeds. |  |
| 11 | Complete consent screens if shown. | PA continues into the app. |  |
| 12 | Confirm landing page after login. | PA lands on Home, not candidate onboarding. |  |
| 13 | Ensure PA is assigned to the intended manager. If no UI exists, ask the technical verifier to create/confirm the assignment. | PA has at least one assigned manager. |  |
| 14 | Log in as PA. | PA lands on Home. |  |
| 15 | Check visible tabs. | Home, Candidates, Events, and Profile are visible. Leads, Team, Admin, and Roadmap are not visible. |  |
| 16 | Open Candidates tab. | PA sees candidates for assigned manager only. |  |
| 17 | Start Add Candidate. | Assigned manager is available in the manager picker. |  |
| 18 | Do not create a candidate unless candidate UAT is being run now. | No accidental candidate is created. |  |
| 19 | Open Invite Member if available from the PA flow. | Candidate is the only invitable role. Staff roles are not available. |  |

## Verifier Checks

Ask a technical verifier to confirm:

- Invitation status changed from pending to accepted.
- PA role is `pa`.
- PA is active and not marked as test data.
- PA has the intended row in `pa_manager_assignments`.

## Pass Criteria

- PA logs in successfully by phone OTP.
- PA skips candidate onboarding.
- PA has assigned manager access.
- PA can access candidate workflows for the assigned manager.
- PA cannot access Leads, Team, Admin, or staff invite roles.

## Fail Or Blocked Examples

- PA has no manager assignment.
- PA sees candidates from the wrong manager.
- PA can invite staff roles.
- PA can access Leads or Team.
- PA lands in candidate onboarding.
