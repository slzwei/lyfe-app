# 6. RO Onboarding UAT

## Goal

Confirm a Recruitment Officer can be invited by admin/director, skips candidate
onboarding, can work with candidates broadly, and can invite candidates only.

## Tester Setup

- Inviter account: Admin or Director.
- New user account: RO.
- App needed: Lyfe mobile app.
- Do not use: ATS or MKTR to create the RO account.

## Preconditions

- Admin onboarding UAT has passed.
- Director onboarding UAT has passed if the director invite path is being tested.
- The RO invite backend fix is deployed:
  - `create-member-invitation` allows admin/director to invite `ro`.
  - `handle_new_user` treats `ro` as staff so RO skips candidate onboarding.
- RO phone number can receive SMS OTP.
- RO phone number is not already used by another Lyfe user.
- For the cross-manager visibility check, the environment has candidates under
  at least two different managers, or that step is recorded as `SKIP`.

## Test Data

```text
Inviter role: Admin / Director
RO full name:
RO phone:
Environment:
App build:
Backend deployment confirmed by:
```

## Steps

| Step | Tester Action | Expected Result | Result |
|---|---|---|---|
| 1 | Log in as Admin or Director. | Inviter lands on Home. |  |
| 2 | Go to Team. | Team screen opens. |  |
| 3 | Tap Invite Member. | Invite form opens. |  |
| 4 | Enter RO full name and 8-digit Singapore phone number. | Fields accept the data. |  |
| 5 | Select role `RO` or `Recruitment Officer`. | RO is selected. |  |
| 6 | Leave manager assignment empty. | No manager assignment is required for RO. |  |
| 7 | Tap Create Invitation. | Success message appears. |  |
| 8 | Check Team pending invitations. | RO invitation appears as pending. |  |
| 9 | Sign out of inviter, or switch to the RO device. | Login screen is ready for RO. |  |
| 10 | RO enters the same invited phone number. | OTP request is accepted. |  |
| 11 | RO enters SMS OTP. | Login succeeds. |  |
| 12 | Complete consent screens if shown. | RO continues into the app. |  |
| 13 | Confirm landing page after login. | RO lands on Home, not candidate onboarding. |  |
| 14 | Check visible tabs. | Home, Candidates, Events, and Profile are visible. Leads, Team, Admin, and Roadmap are not visible. |  |
| 15 | Open Candidates tab. | RO can see the candidate workspace. |  |
| 16 | Confirm candidate scope using known candidates from different managers. | RO can see candidates across managers, or this step is marked `SKIP` if the fixture does not exist. |  |
| 17 | Open Invite Member if available from RO flow. | Candidate is the only invitable role. Staff roles are not available. |  |
| 18 | Attempt to find Team or Leads tabs. | Team and Leads are not available to RO. |  |
| 19 | Confirm RO is not listed as a manager option when assigning an agent or candidate. | RO cannot be selected as an agent manager or candidate assigned manager. |  |

## Negative Permission Checks

Run these only if the app screen makes the action available:

| Check | Expected Result | Result |
|---|---|---|
| Try to invite Agent, PA, Manager, Director, Admin, or another RO. | The role is not visible, or submission is rejected. |  |
| Try to access Leads. | Leads are not visible or access is denied. |  |
| Try to access Team. | Team is not visible or access is denied. |  |
| Try to access Admin. | Admin is not visible or access is denied. |  |

## Verifier Checks

Ask a technical verifier to confirm:

- Invitation status changed from pending to accepted.
- RO role is `ro`.
- RO is active and not marked as test data.
- RO has `onboarding_complete = true` after first login.
- RO is not assigned as an agent manager or candidate manager.

## Pass Criteria

- Admin or Director can create the RO invitation.
- RO logs in successfully by phone OTP.
- RO skips candidate onboarding.
- RO can access candidate/recruitment work.
- RO can invite candidates only.
- RO cannot access Leads, Team, Admin, or staff invite roles.

## Fail Or Blocked Examples

- RO role is missing from Admin or Director invite form.
- Invitation submit returns a permission error.
- RO lands in candidate onboarding.
- RO can invite staff roles.
- RO cannot access the expected candidate workspace.
