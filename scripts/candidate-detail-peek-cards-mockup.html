Why this works →

The core insight: most manager lookups on this screen are status checks — "did Sarah send her resume?", "when was the last contact?", "how far along is her training?" Traditional tabs make those checks a 2-tap operation (tap tab, scan content). Peek cards make them zero-tap — the answer is visible immediately.

What each card surfaces at a glance

  • Progress — fraction complete, what's pending, micro-progress bar. Manager sees readiness without opening.
  • Profile — DISC type + demographics. Enough to recall who this candidate is; full profile one tap away.
  • Docs — top 3 files with timestamps. Answers "is their resume in yet?" without navigation.
  • Activity — last 3 interactions. Preserves the "what happened last?" context instantly.

Why it's not just "cards instead of tabs"

  • Tapping still opens a full section view — same information as the tabbed version, same sheets, same logic. The peek card is an entry point, not a replacement.
  • Count badges surface changes — "Docs 5" and "Activity 3" tell you there's something to check without scanning tabs.
  • Full-width cards let each section show its best shape — Progress gets a real progress bar with pending deadlines. Docs gets a proper file list with sizes. Activity gets room for meaningful one-line summaries of what happened. The cards aren't identical squares — each is optimized for what it needs to communicate.
  • Editorial over dashboard — this is the move the design context calls for. Tabs feel like a dashboard; peek cards feel like a magazine contents page.

Tradeoffs to note

  • Deepest refactor of the five options — requires a "summary view" per section (~2–3 days work).
  • Full detail still requires a tap-in then tap-back. For power users toggling between sections constantly, tabs are marginally faster — but they also miss the preview info.
  • Full-width stacked cards use more vertical scroll than 2×2 — ~4 screens to see all four. Mitigated because each card answers most questions without needing to open it.
  • Doesn't scale cleanly if sections grow to 5+ (would need to add a 5th card below, making the scroll even longer).

Try it: tap any of the 4 peek cards in the mockup above to open its detail view. Back-chevron at the top returns to the home view.
